# MarkdownからPDFコンバーター

このフォルダーには、このリポジトリーからドキュメントページのPDFバージョンを生成するための前処理スクリプトと変換スクリプトが含まれています。

## これが存在する理由

ドキュメントのソースファイルでは、Adobeプラットフォーム固有のマークダウン構文（アコーディオンブロック、アラートコールアウト、画像属性拡張）を使用していますが、これは標準のマークダウンツールでは理解できません。 このスクリプトは、その構文を正規化し、[md-to-pdf](https://github.com/simonhaenisch/md-to-pdf)を使用してファイルをPDFに変換します。また、出力ファイルのサイズを管理できるように画像を圧縮します。

## 前提条件

- [Node.js](https://nodejs.org/) （v18以降）
- 依存関係は既に`node_modules/`にインストールされています。 再インストールする必要がある場合は、このフォルダーから`npm ci`を実行してください。

## 使用状況

変換するマークダウンファイルへのパスを渡して、**リポジトリルート**&#x200B;からスクリプトを実行します。

```
node "scripts/Md to PDF converter/preprocess-for-pdf.js" <path/to/file.md>
```

**例：**

```
node "scripts/Md to PDF converter/preprocess-for-pdf.js" help/substance-3d-general/openpbr/openpbr-overview.md
```

PDFは、ソースファイルと&#x200B;**同じディレクトリ**&#x200B;に書き込まれます。 変換中に作成された一時ファイル（`*.pdf-ready.md`および`_pdf-images/`）は、成功すると自動的に削除されます。 変換に失敗した場合、デバッグに役立つように配置されます。

## スクリプトの機能

| ソース構文 | PDF出力 |
|---|---|
| `+++Title` / `+++`アコーディオンブロック | `#####`の見出しと、常に表示されるコンテンツ |
| `>[!NOTE]`個のアラートコールアウト | 太字の&#x200B;**注：**&#x200B;プレフィックスを持つ標準ブロック引用 |
| `![](path){width="N"}`画像属性 | 指定された幅を保持する`<img>`タグ |
| `.pdf`ファイルへのマークダウン画像リンク | 削除されました（web専用のセルフダウンロード参照） |
| `hold:` frontmatterキー | 削除されました（プラットフォームのみのメタデータ） |
| すべての画像 | 幅が最大1200 pxに変更され、JPEGとして80%の画質で再エンコードされます |
| すべてのテーブル | 注入されたCSSによって削除された境界線と背景 |
