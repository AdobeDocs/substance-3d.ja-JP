# メッシュからの法線マップ

「メッシュからの法線マップ」ベイカーを使用すると、ハイポリメッシュから正接スペースまたはワールド空間法線マップを作成できます。**使用可能：**

* Substance Painter
* Substance Designer
* Substance自動処理ツールキット

## パラメーター

| *パラメーター* | *説明* |
| --- | --- |
| **マップの種類** | ベイカーが出力する標準テクスチャの種類を制御します。有効な値：<ul data-preserve-html="true"><li data-preserve-html="true"><strong>ワールドスペース</strong></li><li data-preserve-html="true"><strong>接線空間</strong> （既定）</li></ul>*Substance Painterでは、このパラメーターは制御できず、接線空間に設定されています。* |
| **法線の向き** | **マップの種類**&#x200B;パラメーターが接線空間に設定されている場合に、標準テクスチャの書式を定義します。指定できる値：<ul data-preserve-html="true"><li data-preserve-html="true"><strong>OpenGL</strong></li><li data-preserve-html="true"><strong>DirectX</strong> （既定）</li></ul>*Substance Painterでは、このパラメーターは[プロジェクト設定](https://experienceleague.adobe.com/ja/docs/substance-3d-painter/using/interface/project-configuration)によって制御されています。* |
