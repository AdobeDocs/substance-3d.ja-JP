# メッシュからの法線マップ

メッシュベイカーの法線マップを使用すると、高いポリメッシュから接線空間またはワールド空間法線マップを作成できます。**次の場所で利用できます：**

* Substance Painter
* Substance Designer
* Substance Automation Toolkit

## パラメーター

| *パラメーター* | *説明* |
| --- | --- |
| **マップの種類** | ベイカーが出力する通常のテクスチャのタイプを制御します。使用可能な値：<ul data-preserve-html="true"><li data-preserve-html="true"><strong> ワールド スペース </strong></li><li data-preserve-html="true"><strong>接線空間</strong> （既定値）</li></ul>*Substance Painterでは、このパラメーターは制御できず、接線空間に設定されています。* |
| **通常の向き** | **マップタイプ** パラメーターが接線空間に設定されている場合の法線テクスチャの形式を定義します。使用可能な値：<ul data-preserve-html="true"><li data-preserve-html="true"><strong>OpenGL</strong></li><li data-preserve-html="true"><strong>DirectX</strong> （既定値）</li></ul>*Substance Painterでは、このパラメーターは[&#x200B; プロジェクト設定](https://experienceleague.adobe.com/en/docs/substance-3d-painter/using/interface/project-configuration).*&#x200B;によって制御されます |
