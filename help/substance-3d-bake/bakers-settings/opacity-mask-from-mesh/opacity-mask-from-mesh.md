# メッシュからの不透明度マスク

メッシュベイカーの不透明度マスクは、逃した光線がグレースケールのバイナリ画像に変換されるテクスチャを計算します。 このテクスチャは、一般的に不透明度マップとして使用されます。

テクスチャのプロパティは次のように定義されます。

* 黒い値は空の領域を表します。
* 白い値は凸状の領域を表します。

**次の場所で利用できます：**

* Painter
* Designer
* Automation Toolkit

## パラメーター：

このベイカーには特定のパラメーターがありません。
