# ベイクドテクスチャのビット深度は何ですか？

>[!WARNING]
>
> **質問**
> 
> ベイクドテクスチャのビット深度は何ですか？

>[!NOTE]
>
> **解決策：Substance Designer**
> 
> ビット深度は、テクスチャの保存に使用するターゲットファイルフォーマットによって異なります。

>[!NOTE]
>
> **解決策：Substance Painter**
> 
> ベイカー出力は、16ビットRGBAテクスチャとして生成されます。 最終的なビット深度は、テクスチャの保存に使用するターゲットファイルフォーマットによって異なります。 32bitsファイル形式では、16bitsの入力情報は変換されますが、それ以上の精度は得られません。

>[!NOTE]
>
> **ソリューション: Substance自動処理ツールキット**
>
