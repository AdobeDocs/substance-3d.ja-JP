# ベイクしたマップを書き出す方法は？

>[!WARNING]
>
> **質問**
> 
> メッシュからベイクしたテクスチャを書き出して、別のアプリケーションで使用するにはどうすればよいですか？

>[!NOTE]
>
> **解決策：Substance Designer**
> 
> ベイカーの出力ファイルは、メッシュがリンクされているSubstance グラフの横に配置する必要があります。 右クリックして「探索」を選択し、アプリケーションのエクスプローラーウィンドウにファイルを表示します。

>[!NOTE]
>
> **解決策：Substance Painter**
> 
> ベイカーの出力ファイルは、プロジェクトファイル（\*.spp）内に保存されます。 それらを書き出すには、次のいずれかを実行できます。
> 
> * **ファイル/テクスチャを書き出し** ダイアログを使用し、書き出しプリセットの「メッシュマップ」を選択します
> * シェルフ内の焼き付けテクスチャを右クリックし、「書き出し」を選択します。

>[!NOTE]
>
> **解決策：Substance Automation Toolkit**
> 
> ベイカーの出力ファイルは、デフォルトではメッシュの横に保存されます。 出力フォルダーは、コマンドラインの特定の引数を使用して変更できます。
