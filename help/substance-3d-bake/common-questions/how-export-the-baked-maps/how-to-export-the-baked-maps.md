# ベイク済みマップを書き出す方法を教えてください。

>[!WARNING]
>
> **質問**
> 
> メッシュからベイクしたテクスチャを書き出して、別のアプリケーションで使用する方法を教えてください。

>[!NOTE]
>
> **解決策：Substance Designer**
> 
> ベイカーの出力ファイルは、メッシュがリンクされているSubstanceグラフの横に配置する必要があります。 右クリックして「エクスプローラ」を選択し、アプリケーションのエクスプローラ・ウィンドウでファイルを表示します。

>[!NOTE]
>
> **解決策：Substance Painter**
> 
> ベイカーの出力ファイルは、プロジェクトファイル(\*.spp)に保存されます。 これらのファイルを書き出すには、次のいずれかの操作を行います。
> 
> * **ファイル/テクスチャを書き出し**&#x200B;ダイアログを使用して、書き出しプリセット「メッシュマップ」を選択します
> * シェルフのベイク処理されたテクスチャを右クリックし、「エクスポート」を選択します。

>[!NOTE]
>
> **ソリューション: Substance自動処理ツールキット**
> 
> デフォルトでは、ベイカーの出力ファイルはメッシュの横に保存されます。 出力フォルダーは、コマンドラインの特定の引数で変更できます。
