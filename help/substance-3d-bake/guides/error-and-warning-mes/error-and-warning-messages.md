# エラーメッセージと警告メッセージ

以下は、Substanceソフトウェアでベイク処理を行ったときに表示される可能性のあるすべてのエラーメッセージのリストです。

## パン屋

| *メッセージ* | *説明* |
| --- | --- |
| Bakerは利用できません。 | このエラーメッセージの後には、通常、GPUの問題に関連する追加のエラーメッセージが表示されます。 GPUが古すぎて、ソフトウェアの[技術要件](https://www.allegorithmic.com/products/tech-specs)を満たしていない場合に発生する可能性があります。 |
| UVセット[X]がありません。 | Bakerは、ローポリメッシュに存在しない特定のUVセットで作業しようとしました。 |
| URLからシーンを読み込めません。 | このメッセージは、ベイカーがメッシュファイル（通常はhigh poly mesh）を読み込めなかったことを意味します。 このメッセージの原因となる理由はいくつかあります。<ul data-preserve-html="true"><li data-preserve-html="true">参照されているメッシュファイルは存在しません。</li><li data-preserve-html="true">メッシュファイルが破損しているか壊れているため、読み取れません。</li><li data-preserve-html="true">メッシュは現在別のアプリケーションによって編集されているため、読み取ることができません。</li></ul> |

## SVGベイカーへの紫外線

| *メッセージ* | *説明* |
| --- | --- |
| メッシュ[メッシュ名]のUVが見つかりませんでした。 | 特定のメッシュに関するUVは見つかりませんでした。 これは、複数のメッシュをインポートしても、一部のメッシュだけにUVがある場合に起こります。 |
| シーンにUVがありません。 ベイク処理をキャンセルしています。 | シーン内にUVを持つメッシュがない場合、ベイク処理はキャンセルされます。 |

## Position Baker

| *メッセージ* | *説明* |
| --- | --- |
| メッシュ[メッシュ名]には位置がありません。 | ローポリゴンメッシュには頂点位置がありません。 |
| メッシュ[メッシュ名]にUVセット[X]のUVがありません。 | Bakerは、ローポリメッシュに存在しない特定のUVセットで作業しようとしました。 |

## 「From Mesh」ベイカー

| *メッセージ* | *説明* |
| --- | --- |
| メッシュ[メッシュ名]に頂点法線が見つかりませんでした。 | 指定されたメッシュに頂点法線が見つかりませんでした。 メッシュに頂点法線がない場合は、頂点法線が再計算されるため、通常は発生しません。 これは、カスタム接線空間プラグインの障害が原因で発生する可能性があります。 |
| メッシュ[メッシュ名]に頂点の接線が見つかりませんでした。 | 上記と同じです。 |
| メッシュ[メッシュ名]に頂点の従法線が見つかりませんでした。 | 上記と同じです。 |
| メッシュ[メッシュ名]に頂点カラーが見つかりませんでした。 | 指定されたメッシュに頂点カラーが見つかりませんでした。 これは、高ポリゴンメッシュ内の少なくとも1つのサブメッシュに頂点カラーが定義されていない場合に発生する可能性があります。 |
| 高ポリゴンのデータが不足しているため、選択したベイカーを使用できません。 ベイク処理を中断します。 | 前に上記のメッセージの少なくとも1つが付きます。 通常、シーンに欠落しているデータが少ししかない場合（例：高ポリゴンのシーンで1つのメッシュだけが頂点カラーを持っていない場合）、ベイク処理は欠落しているデータをゼロで埋め、ベイク処理を続行します。 不足しているデータが多すぎる場合、このメッセージが出力され、ベイク処理が停止されます。 |

## メッシュから転送されたテクスチャ

| *メッセージ* | *説明* |
| --- | --- |
| 詳細テクスチャのロードに失敗しました。 | パンの設定で定義されたテクスチャを読み込めませんでした。 これは、ファイルがディスク上に実際に見つからないか、ファイルが破損して読み取れないことが原因である可能性があります。 |
