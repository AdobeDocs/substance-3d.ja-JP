# エラーと警告メッセージ

Substance ソフトウェアを使用してベイク処理を行う際に表示される可能性のあるすべてのエラーメッセージのリストを以下に示します。

## どのパン屋も

| *メッセージ* | *説明* |
| --- | --- |
| ベイカーは利用できません。 | このエラーメッセージの後には、通常、GPUの問題に関連する追加のエラーメッセージが続きます。 GPUが古すぎて、ソフトウェアの[技術要件](https://www.allegorithmic.com/products/tech-specs)を満たしていない場合に発生する可能性があります。 |
| UV セット [X]が存在しません。 | ベイカーは、ローポリメッシュに存在しない特定のUV セットを使用しようとしました。 |
| URLからシーンを読み込めません。 | このメッセージは、ベイカーがメッシュファイル（通常はハイポリメッシュ）をロードできなかったことを意味します。 このメッセージのソースとなる理由はいくつかあります。<ul data-preserve-html="true"><li data-preserve-html="true">参照されているメッシュファイルが存在しません。</li><li data-preserve-html="true">メッシュファイルが破損しているか破損しているため、読み取れません。</li><li data-preserve-html="true">メッシュは現在別のアプリケーションで編集中のため、読み取れません。</li></ul> |

## UVからSVG・ベイカーへ

| *メッセージ* | *説明* |
| --- | --- |
| メッシュ [ メッシュ名]のUVが見つかりませんでした。 | 特定のメッシュに関するUVは見つかりませんでした。 これは、複数のメッシュが読み込まれても、一部のメッシュだけがUVを持っている場合に発生する可能性があります。 |
| シーンにはUVがありません。 ベイクのキャンセル。 | シーン内のメッシュにUVがない場合、ベイク処理はキャンセルされます。 |

## 位置ベイカー

| *メッセージ* | *説明* |
| --- | --- |
| メッシュ [ メッシュ名]に位置がありません。 | ローポリメッシュには頂点の位置がありません。 |
| メッシュ [ メッシュ名]には、uv セット [X]のUVがありません。 | ベイカーは、ローポリメッシュに存在しない特定のUV セットを使用しようとしました。 |

## Any &quot;From Mesh&quot; Baker

| *メッセージ* | *説明* |
| --- | --- |
| メッシュ [ メッシュ名]に頂点法線が見つかりませんでした。 | 指定されたメッシュに頂点の法線が見つかりませんでした。 頂点の法線は、メッシュに含まれていない場合に再計算されるため、通常は発生しません。 カスタム接線空間プラグインの欠陥が原因で発生する可能性があります。 |
| メッシュ [ メッシュ名]に頂点の接線が見つかりませんでした。 | 上記と同じです。 |
| メッシュ [ メッシュ名]に頂点の従法線が見つかりませんでした。 | 上記と同じです。 |
| メッシュ [ メッシュ名]に頂点カラーが見つかりませんでした。 | 指定されたメッシュに頂点カラーが見つかりませんでした。 これは、ハイポリメッシュ内の少なくとも1つのサブメッシュに頂点カラーが定義されていない場合に発生する可能性があります。 |
| 選択したベイカーを使用するには高いポリゴン内のデータが不足しています。 ベイクの中止。 | 上記のメッセージの少なくとも1つを先頭に付けます。 通常、シーン内にデータが少ししか見つからない場合（例：高いポリシーンのメッシュのうち1つだけが頂点カラーを持たない場合）、ベイク処理では見つからないデータにゼロを入力し、ベイク処理を続けます。 あまりにも多くのデータが欠落している場合、このメッセージが出力され、ベーキングプロセスが停止されます。 |

## メッシュからの転送されるテクスチャ

| *メッセージ* | *説明* |
| --- | --- |
| 詳細テクスチャの読み込みに失敗しました。 | パン屋の設定で定義されたテクスチャを読み込めませんでした。 これは、ファイルが実際にディスク上に存在しないか、またはファイルが破損していて読み取れないことが原因である可能性があります。 |
