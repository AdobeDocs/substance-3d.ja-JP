# よくある質問

+++新しいADAポータルとは何ですか？また、このポータルで何ができますか？


ADAポータルは、ライセンスと資格認定を管理するための中心的な場所として機能します。 ADAポータルでは、次の操作を実行できます。



* 現在および以前のライセンスをダウンロードします。

現在および以前のライセンスをダウンロードします。

* デジタル資格認定へのアクセスとダウンロード

デジタル資格認定へのアクセスとダウンロード

* アカウントに関連付けられている連絡先を追加または削除します。

アカウントに関連付けられている連絡先を追加または削除します。

+++

+++注文確認メールが届かない場合はどうすればよいですか？


まず、スパムまたは迷惑メールフォルダーをチェックして、メールが迷惑メールとして処理されていないことを確認します。 それでもメールが見つからない場合は、アカウントマネージャーまたはCSMに連絡してください。



+++

+++以前のバージョンのソフトウェアをインストールするにはどうすればよいですか？
ソフトウェアの古いバージョンを参照してダウンロードするには、次の手順を実行します。

* ADAのダウンロードセクションを開きます。

* 「他のバージョン」をクリックします。

+++

+++知り合いを追加または削除するにはどうすればよいですか？


アカウントを追加するには、次の手順を実行します。

* ページヘッダーから連絡先を開きます。

* 「Add Contact」をクリックします。

* 連絡先情報を入力します。

* 「保存」をクリックします。





連絡先を削除するには、次の手順に従います。

* ページヘッダーから連絡先を開きます。

* アカウント名の横のチェックボックスをオンにします。

* ページ右側の「連絡先の削除」をクリックします。



+++

+++ポータルへのログインに問題があります。 どうすればよいですか？


間違った電子メールまたはパスワードに関連するエラーメッセージが表示された場合は、アカウントに関連付けられている正しい資格情報を使用していることを確認してください。





別の種類のエラーが発生した場合は、[弊社のエンタープライズサポートにお問い合わせください](https://helpx.adobe.com/enterprise/using/support-for-enterprise.html)。



+++

+++以前の注文履歴を確認するにはどうすればよいですか？
発注履歴には、LWSポータルからのみアクセスできます。 LWSポータルにアクセスするには：

* [Adobeライセンスwebサイト](https://licensing.adobe.com/)に移動します。

* LWSアカウントにログインします。

* 「レポート」をクリックします。

* 「購入履歴を表示」を選択します。

* Adobe注文番号を入力します。

* 「検索」をクリックします。

[LWSの詳細については、こちらを参照してください](https://helpx.adobe.com/x-productkb/policy-pricing/volume-licensing-site.html)。



+++

+++さらにサポートが必要な場合の問い合わせ先を教えてください。
さらにサポートが必要な場合は、エンタープライズサポートチームにお問い合わせください。 管理者は、[AdobeのAdmin Consoleにログインし、サポートケースを開く](https://helpx.adobe.com/enterprise/using/support-for-enterprise.html)必要があります。

さらにサポートが必要な場合は、AdobeのCSMに連絡してください。

+++

+++ADAのライセンスキーファイルを使用してソフトウェアをライセンス認証できません。
[ライセンス認証の詳細な手順については、こちらを参照してください](../../../ecosystem/for-linux/substance-for-linux.md)。 問題が解決しない場合は、[エンタープライズサポートチームにお問い合わせください](https://helpx.adobe.com/enterprise/using/support-for-enterprise.html)。
