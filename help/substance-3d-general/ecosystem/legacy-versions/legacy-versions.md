# 従来のバージョン

従来のバージョンは、Adobeアカウントのアクティベーションに移行する前に導入されていた、従来のライセンスキーのファイルアクティベーションシステムと互換性のあるSubstance 3Dアプリケーションです。 これらのバージョンは、AdobeアカウントまたはSteamアカウントを介して購入されたライセンスと互換性がありません。

Substance 3D PainterおよびDesignerの旧バージョンをダウンロードするには、次のアドレスにアクセスしてください。\
<https://www.substance3d.com/legacy-builds/>
