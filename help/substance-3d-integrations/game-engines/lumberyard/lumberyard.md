# 造材所

![](../../assets/lumber.jpg){width="800px"}

このSubstance engineは、Windows、Mac、PS4、およびXbox One向けのLumberyardパッケージビルドで機能します。 また、Substanceプラグインは、Lumberyard Editor （WindowsおよびMac）のすべてのバージョンと互換性があります。

プラグインは、エンジンにネイティブに統合されています。
