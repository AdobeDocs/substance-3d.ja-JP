# 画像入力の使用

Substanceの入力パラメーターでイメージを使用するには、次の手順を実行します。

1. Substance グラフのインスペクターウィンドウで、プロジェクト内のテクスチャを選択して、画像入力に割り当てることができます。

   ![](../../../assets/imageinput-inspector.png)
1. テクスチャを選択すると、「読み取り/書き込み可能」テクスチャがオンになります。これは、Substanceマテリアルにテクスチャデータを読み取るために必要です

   ![](../../../assets/imageinput-texture.png)
