# 画像入力の使用

Substanceの入力パラメータでイメージを使用するには、次の手順に従います。

1. Substance グラフのインスペクタウィンドウで、プロジェクト内のテクスチャを選択してイメージ入力に割り当てることができます。

   ![](../../../assets/imageinput-inspector.png)
1. テクスチャを選択すると、テクスチャの「読み取り/書き込み可能」フィールドがチェックされます。これは、テクスチャデータをSubstanceマテリアルに読み込むために必要です

   ![](../../../assets/imageinput-texture.png)
