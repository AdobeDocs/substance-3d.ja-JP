# プロジェクト間でのSbsarファイルの共有

.sbsprsファイルを使用することで、同じパラメーター調整を維持しながら、.sbsarファイルをプロジェクトとコンピューターの間で共有できます。

元のプロジェクトのマテリアルを、共有する設定に変更したら、インスペクターパネルでプリセット設定に移動します。 プリセット設定で、新しいプリセットを作成し、名前を入力します。 この新しい名前付きプリセットは、このマテリアルのプリセットのリストに表示されます。 完了したら、プリセットを書き出してローカルに保存します。

別のプロジェクトまたはコンピューターで.sbsarを使用する場合は、書き出されたプリセットファイルも含めます。 sbsarがUnityプロジェクトにインポートされたら、プリセット設定に移動し、インポートオプションを選択します。 前の手順で作成したプリセットファイルを選択して、読み込みます。 前のプロジェクトの設定を含むプリセットをプリセットリストに追加する必要があります。

共有されているすべてのマテリアルに対して、この手順を繰り返します。
