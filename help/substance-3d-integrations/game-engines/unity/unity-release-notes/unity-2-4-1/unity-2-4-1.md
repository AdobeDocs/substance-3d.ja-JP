# Unity 2.4.1

## バグ修正/アップデート：

* HDRPを使用する場合、生成されるHDRP マテリアルのメタリック値は0に設定されます。 デフォルトの1.0に修正しました。
* HDRPマスク出力がsRGBに設定されました – 固定でsRGBが無効になります。
* Substance以外のテクスチャでは、読み取り/書き込みが有効になっていません
* Androidは64ビットを適切にサポートするようになりました。
* Mac OSで修正されたSubstance Sourceが読み込まれない
