# Unity 3.0.0

2021年6月27日リリース

更新/追加：

* Apple Siliconのサポート
* プラグインの使用方法に関する新しいYouTubeチュートリアル
* 新しいスクリプト作成文書
* Substance グラフエディターおよびメインサブスタンスファイルエディターでのcontrol-zのサポート
* 多数のsbsarファイルを読み込む際のパフォーマンスが向上しました。
* 複数のグラフを持つSubstance マテリアルのサポート
* グラフ管理用のUIを変更
* C#経由でプリセットを読み込むAPIを表示
* 更新されたオンラインドキュメント

修正：

* ランダム化ボタンを何度も押すと、インスペクターにバグが表示される
* Substanceのアップデートを中断するNULL テクスチャ入力
* 「すべての出力を生成」、「ミップマップを生成」および「ランタイムのみ」トグルが機能しない
* 名前空間に関する問題
* グラフアセットを選択して再生モードに入ると、Null参照エラーが発生する
* ランタイムのみのマテリアルを使用する場合の、最新の2021.3 LTSバージョンのUnityのHDRPおよびURPの問題
* 複数入力を伴うsbsarファイルのパフォーマンスの問題
* 「ハンドルは既にリリースされています」エラー
* 「再生モードを開始すると青にシフトされる」問題
* sbsarファイルのHeightマップの問題
* 画像入力が読み取り不能なテクスチャを読み取る際の問題

既知の問題：

* 出力テクスチャのRチャンネルとBチャンネルが反転するMacの問題を修正
* Macのパフォーマンスの大幅な向上
