# Unity 2.4.3

2019年12月リリース

バグ修正：

* 固定：法線マップ反転
* 修正：インスペクター内での開始垂直位置の問題
* 修正：インスペクターグラフの「生成されたテクスチャ」セクションでのスクロールバーの処理。 テキストのクリーンアップのデバッグ
* 修正：プラットフォーム解決のホバーテキストに「PC、Max、Linux」というスペルエラーが表示される
* 修正：プラットフォーム解像度の設定を変更して「マテリアル」ナビゲーションボタンをクリックすると、エラーが発生する
* 修正：HDRP パッキングがAOを正しく処理していません。 マスクマップのグリーンチャンネルが黒になる
* 修正： （回帰、Macのみ）有効なテクスチャマップがない数値出力/SubstanceクラッシュUnity。
* 修正：パラメーターを変更し、Substanceの別のインスタンスをクリックするとクラッシュが発生する。
* 修正：メインSubstanceオブジェクトをクリックしてSubstanceグラフをクリックすると、GUIエラーが発生する（2019.2以降のみ）
* 修正：Unity 2019.3 sbsar ファイルのインポート時のエラー
* 修正：スクリプトにレンダリング呼び出しがない限り、Duplicate()関数でSubstanceが完全にレンダリングされない
