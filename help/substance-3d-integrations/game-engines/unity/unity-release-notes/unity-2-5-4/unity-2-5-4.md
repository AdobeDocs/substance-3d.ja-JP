# Unity 2.5.4

2020年12月9日リリース

修正：

* UnityプロジェクトにSubstanceのマテリアルが含まれている場合、ビットコード互換のiOSアプリケーションを生成できない

既知の問題：

* Unityのソースからアセットを一貫してダウンロードできない。 [Substance Source webサイト](https://source.substance3d.com/)からダウンロードして、アセットを手動でインポートしてください。
* Unity 2020.2以降は現在サポートされていません
