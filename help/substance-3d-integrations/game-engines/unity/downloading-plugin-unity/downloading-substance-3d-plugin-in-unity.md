# UnityでのSubstance 3Dプラグインのダウンロード

## アセットストア

Unity用Adobe Substance 3Dは、[Unity Asset Store](https://assetstore.unity.com/packages/tools/utilities/substance-3d-for-unity-beta-213208)で利用できます。 プラグインがアセットフォルダーのプロジェクトに追加されます。

## パッケージマネージャー

Asset Store経由でプラグインを追加してダウンロードすると、**My Assets**&#x200B;の下にあるPackage Manager （Unity 2020.3.27x以降）を使用してプラグインにアクセスできます。

![](https://helpx-prod.scene7.com/is/image/HelpxProd/screen-shot-2022-03-29-at-10-45-20-am?$png$&jpegSize=300&wid=1920)

### パッケージマネージャーキャッシュ

アセットストアのキャッシュは、パッケージマネージャー/マイアセットに表示されるバージョンに影響を与える場合があります。 最新バージョンが入手できない場合は、アセットストアキャッシュを削除する必要がある可能性があります。\
