# ゲームエンジン

Substanceプラグインを使用して、ほとんどの主要エンジンでSubstanceファイル(.sbsar)を読み込むことができます。

* <b>Unity</b>には、Substanceプラグインが2017リリースサイクル用にネイティブに統合されています。 Unity 2018以降の場合、Substanceプラグインは[Unity Asset Store](https://assetstore.unity.com/packages/tools/utilities/substance-in-unity-110555)で使用できます。
* <b>アンリアルエンジン</b>プラグインは、[アンリアルマーケットプレイス](https://accounts.unrealengine.com/logout?redirectUrl=https%3A%2F%2Fwww.unrealengine.com%2Fmarketplace%2Fsubstance-plugin)にあります。
* <b>Lumberyard</b>プラグインはネイティブに統合されています。
* <b>CRYENGINE</b>プラグインは、Crytekによってネイティブに統合および管理されています。 詳細については、[Substance CRYENGINEのドキュメント](https://docs.cryengine.com/pages/viewpage.action?pageId=44968527)を参照してください
