# アンリアルプラグイン4.26.0.2

追加：

* Substance enginev 8.0.3のサポート
* Substance Sourceの操作でSubstanceランチャー内の「ソース」タブにアクセスできるようになり、アセットがUE4に直接送信されるようになりました（[詳細](../../../../../game-engines/unreal-engine/unreal-engine-4/source-in-ue4/source-in-ue4.md)）
* プロジェクトバージョンのアップグレード時に1度に処理されるSubstanceマテリアルの数を削減

修正：

* UE4 Substanceプラグインがインストールされている状態でエディターを閉じると、MacでUE4がクラッシュする
* Substance グラフインスタンスのtextパラメーターを変更すると、フリーズし、最終的にクラッシュします
