# Substance入力画像 – UE4

Substanceは、マテリアルで処理するイメージを指定できる入力を使用して作成できます。 これにより、ベイク処理されたメッシュデータまたはパターンを入力として取り、マテリアルを変更したり、アセットに適合させることができるモジュール化されたマテリアルを作成できます。 テクスチャをSubstance Inputとして使用するには、テクスチャをSubstance Input TextureとしてUE4に読み込む必要があります。読み込むには、テクスチャをUE4にSubstance入力テクスチャとして読み込みます。

1. テクスチャをコンテンツブラウザに読み込みます。 フォーマットとして、「Substance画像入力(jpg、tga、jpeg)」を選択します。
1. このテクスチャをSubstance入力で使用できるようになりました。
