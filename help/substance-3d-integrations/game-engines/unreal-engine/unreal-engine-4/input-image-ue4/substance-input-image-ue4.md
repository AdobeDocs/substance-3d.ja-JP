# 入力画像 - UE4

Substanceは、入力を使用して作成できます。入力を使用すると、マテリアルで処理する画像を指定できます。 これにより、ベイクされたメッシュデータまたはパターンを入力として取り、マテリアルをアセットに合わせて変更または調整できるモジュール化されたマテリアルを作成できます。 テクスチャをサブスタンス入力として使用するには、Substance入力テクスチャとしてUE4にインポートする必要があります。

1. テクスチャを[コンテンツブラウザ]に読み込みます。 フォーマットとして、「Substance画像入力(jpg、tga、jpeg)」を選択します。
1. このテクスチャはSubstance入力で使用できるようになりました。
