# 入力画像 - UE5

Substanceは、マテリアルで処理する画像を指定できる入力を使用して作成できます。 これにより、ベイクされたメッシュデータまたはパターンを入力として取り、アセットのマテリアルを変更または確定できるモジュール化されたマテリアルを作成できます。

* UTexture2DはSubstance入力で使用できます。
