# Substance入力画像 – UE5

Substanceは、マテリアルで処理するイメージを指定できる入力を使用して作成できます。 これにより、ベイク処理されたメッシュデータまたはパターンを入力として取り、マテリアルをアセットに変更または確認できるモジュール化されたマテリアルを作成できます。

* UTexture2DはSubstance入力で使用できます。
