# Substance 3Dプラグインのデフォルトテンプレート

*注意：この機能は現在開発中です。まもなく利用できるようになります。*

バージョン5.0.0では、マテリアルテンプレートワークフロー&#x200B;*が改良され、Substance engineで数値の出力がサポートされるようになりました。 マテリアルテンプレートを使用すると、UE5でのSubstanceマテリアルシェーダの設定方法を正確に定義できます。*
