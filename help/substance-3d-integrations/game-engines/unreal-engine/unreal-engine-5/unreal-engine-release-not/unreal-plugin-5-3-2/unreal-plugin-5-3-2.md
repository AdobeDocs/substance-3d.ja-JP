# Unrealプラグイン5.3.2

2023年12月4日リリース

<b>修正済み</b>

* Unreal エンジン 5.3のMacでSubstanceプラグインが機能しない問題を修正しました。
* Unreal エンジンのSubstanceプラグインでマテリアルチャンネルの選択を解除してもクラッシュが発生しない問題を修正しました
* プラグインの「stone-arc.sbars」マテリアルで、変更可能なすべてのマテリアルプロパティが表示されるのではなく、「入力」セクションの下に「出力サイズ」オプションのみが表示される問題を解決しました
* Substanceプラグインで、読み込んだマテリアルが正しく表示されず、赤くシフトされた法線とオフカラーのベースマップが表示されるカラーシフトの問題を修正しました。
* .sbsar ファイルに対して「再読み込み」を使用するとエディタがクラッシュするSubstanceプラグインのクラッシュの問題を修正しました。
* Substanceプラグインでの入力検証を改善し、キーマテリアルのプロパティフィールドの範囲外や無効なエントリを防ぎます。」
* Substanceプラグインで2つ目のグラフインスタンスを作成すると、以前に読み込んだすべてのプリセットが削除されるバグを修正しました。
* Substanceのファクトリインスタンスを再読み込みすると、既存のすべてのプリセットが削除される問題を修正しました。
