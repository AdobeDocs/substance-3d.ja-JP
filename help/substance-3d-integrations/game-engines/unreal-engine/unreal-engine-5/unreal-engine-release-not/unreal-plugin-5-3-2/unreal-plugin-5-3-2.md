# Unrealプラグイン5.3.2

2023年12月4日リリース

<b>修正済み</b>

* Mac for Unreal Engine 5.3でSubstanceプラグインが機能しない問題を修正しました。
* Unreal EngineのSubstanceプラグインでマテリアルチャンネルの選択を解除してもクラッシュしない問題を修正しました
* プラグインの「stone-arc.sbars」マテリアルで、変更可能なすべてのマテリアルプロパティが表示されるのではなく、「入力」セクションの下に「出力サイズ」オプションのみが表示される問題を解決しました
* 読み込んだマテリアルが正しくない赤くシフトされた法線とオフカラーのベースマップを表示する、Substanceプラグインのカラーシフトの問題を修正しました。
* .sbsarファイルに対して「再読み込み」を使用するとエディターがクラッシュする、Substanceプラグインのクラッシュの問題を修正しました。
* Substanceプラグインの入力検証を改善し、キーマテリアルプロパティフィールドの範囲外や無効なエントリを防ぎます。」
* Substanceプラグインで2番目のGraphインスタンスを作成すると、以前に読み込んだすべてのプリセットが削除されるバグを修正しました。
* Substanceのファクトリインスタンスを再読み込みすると、既存のすべてのプリセットが削除される問題を修正しました。
