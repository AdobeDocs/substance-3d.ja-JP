# 3ds MaxのRedshift

## 3ds MaxプラグインのSubstance

Substanceプラグインは、Redshiftレンダリングプリセットを介してRedshiftをサポートします。 このプリセットを使用すると、Redshift マテリアルに接続されたSubstance出力が自動的に設定されます。
