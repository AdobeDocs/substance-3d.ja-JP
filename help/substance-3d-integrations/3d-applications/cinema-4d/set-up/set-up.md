# Set-Up

## 要件

Cinema 4D R16以上が必要です。 Cinema 4Dライト以外のすべてのバージョンがサポートされています。

Substanceファイルは、[Substance Designer](https://www.allegorithmic.com/products/substance-designer)を使用して作成される可能性があります。

## インストール

## Windows

1. インストール中はCinema 4Dを実行しないでください。
1. セルフインストールパッケージを実行します。
1. 保存先フォルダーを選択または確認します。 これは、プラグインサブフォルダーではなく、Cinema4Dがインストールされたフォルダーである必要があります。
1. 「インストール」をクリックします。
1. インストールが成功すると、Cinema 4Dを開始するオプションが表示されます。

## MAC OS X

1. インストール中はCinema 4Dを実行しないでください。
1. cldファイルをCinema 4Dプラグインフォルダーにドロップします。
1. 通常どおりにCinema 4Dを開始します。
