# ショートカットとナビゲーション

ショートカットのリストは、アドオン環境設定の下部にあります。 各ショートカットのキーバインディングは、「キー」フィールドに目的のキーを入力してカスタマイズできます。 Ctrl、Shift、Altも各ショートカットに対して有効にできます。

デフォルトのキーバインディングは次のとおりです。

* **フローティングメニュー** - CTRL + SHIFT + U
* **SBSARを読み込む** - CTRL + SHIFT + L
* **現在のマテリアルを適用** - CTRL + SHIFT + U
