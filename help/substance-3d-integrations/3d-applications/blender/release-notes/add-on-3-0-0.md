# アドオン3.0.0以降

**アドオン3.1.0**.*リリース日： 2026年10月20日*

**ブレンダーアドオン：**

* &amp;lbrack;Bug&amp;rbrack；修正されたライブラリパスが機能しない
* &amp;lbrack；バグ&amp;rbrack;マルチスレッドにおけるコンテキストの問題を修正し、SBSARの読み込み/アップデートを行わない
* &amp;lbrack;Bug&amp;rbrack；修正されたテクスチャ書き出しフォーマットは無視されます
* &amp;lbrack；パフォーマンス&amp;rbrack；複数のパフォーマンスの向上

**Substance統合ツール（Substanceリモートエンジン）:**

* &amp;lbrack;Feature&amp;rbrack; Substance engine 9.6.1に更新
* &amp;lbrack;Performance&amp;rbrack；依存関係の更新と複数のパフォーマンスの向上

**アドオン3.0.1**.*リリース日： 2026年2月*

**ブレンダーアドオン：**

* &amp;lbrack；固定&amp;rbrack;パラメータの最小値/最大値が機能しない
* &amp;lbrack;Fixed&amp;rbrack; 物理サイズがカスタムシーンスケールで機能しない
* &amp;lbrack；固定&amp;rbrack; 物理サイズが非メートルシステムユニットで動作しません
* &amp;lbrack;Fixed&amp;rbrack; Clearcoatマップがブレンダー4+で機能しない
* &amp;lbrack;Fixed&amp;rbrack; Clearcoatカラーマップがシェーダーにありません
* &amp;lbrack;Fixed&amp;rbrack;アドオン定義のラベルが間違っています
* &amp;lbrack；固定&amp;rbrack; SubstanceがSRE （カラーfloat4値）にランダムなクラッシュを付けます。
* &amp;lbrack；固定&amp;rbrack;イメージ入力がパラメータリストに表示されない
* &amp;lbrack;Fixed&amp;lbrack;ブレンダーを閉じてから再度開くと、画像入力が機能しない

**Substance統合ツール（Substanceリモートエンジン）:**

* バージョン3.0.1へのアップグレード
* 新しいLinuxコンパイル用にC++11 ABIを削除
