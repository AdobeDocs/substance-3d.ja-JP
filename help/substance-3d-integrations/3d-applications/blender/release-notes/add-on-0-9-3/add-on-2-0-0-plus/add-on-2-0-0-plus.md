# アドオン2.0.0以降

## アドオン2.2

<b>追加：</b>

* オクタンレンダラーのサポート
* Redshiftの初期サポート
* Rendermanの初期サポート

<b>更新日：</b>

* コネクタの最新バージョンにアップグレード
* コネクターを使用してプリセットを受信する機能が追加されました
* インポートプリセット機能の強化：マテリアルを含むSBSARのすべてのインスタンスがプリセットを追加するようになりました
* 標準化されたコネクタ機能

<b>修正済み：</b>

* ブレンドファイルの保存後に入力画像が機能しない持続性のバグ
* シェーダプリセットの更新時にシェーダネットワークが機能しない問題
* プラグインダウンロードボタンのURLが間違っている
* オクタンの逆タイリング
* サードパーティレンダラーの入力値が機能しない
* float入力値パラメーターが作成されない問題
* Rendermanカラースペースが正しく機能しない
* シェーダプリセットが使用可能なレンダラーでフィルタリングされない

## アドオン2.1.1

このアップデートには、Blender 4.0以降のサポートと、アドオン環境設定のいくつかの新機能が含まれています。 Substance 3D Samplerとブレンダー（送信先）間でデータをシームレスに転送するためのSubstance Connectorのサポートも追加され、いくつかのバグが修正されました。 詳しくは、以下のリリースノートをご覧ください。

<b>追加/更新：</b>

* Substance Connectorの機能が追加されました（SBSARファイルとUSDファイルをサポート）。
* Blender 4.0以降をサポート
* SREバージョン2.1.0のサポート。
* アドオンの環境設定：
  * Substance統合ツールのインストールパスを選択できます。
  * ボタンをクリックして、統合ツールをデフォルトのパスにリセットします。
  * ボタンをクリックして、統合ツールフォルダーを開きます。
  * マテリアルを割り当てる適用タイプが追加されました（挿入：メインマテリアルとして設定、追加：リストの一番下に追加）。
  * 入力グループのデフォルトの動作（折りたたみ/展開）を選択するチェックボックスが追加されました。
  * 「テクスチャのみを更新」プロパティのデフォルトの動作を選択するチェックボックスが追加されました。
  * ブレンダーを開くときにSubstanceリモートエンジンを自動的に開始します（コネクターを使用している場合は有効にすることが重要です）。
* アドオン内：
  * 更新テクスチャのみを追加（ノードグラフを再作成せずにパラメーターを変更できます）。
  * 「すべてのグループを展開」ボタンと「すべてのグループを折りたたむ」ボタンが追加されました。
  * SBSARで必要な場合にすべての入力画像をグループ化するための入力画像グループが追加されました。
  * パラメーター入力がDesignerと同じ順序で表示されるようになりました。
  * 各マテリアルのサムネールプレビューが追加されました。

<b>修正済み：</b>

* 空の一般入力グループのバグを修正しました。

<b>既知の問題：</b>

* オブジェクト選択時にSBSARを自動選択する機能は、現時点では機能しないため、無効になっています。

## アドオン2.0.0

Substance 3Dアドオン2.0は、完全にリファクタリングされたプラグインアーキテクチャを特徴とする、Blenderユーザーのためのトランスフォーマティブアップデートをマークします。 この再設計では、シームレスな統合、パフォーマンスの向上、将来の拡張に向けた柔軟な基盤に重点を置いています。 これは単なるアップグレードではなく、3Dプロフェッショナルの進化するニーズに対応しながら、BlenderでのSubstance素材の取り扱いを再考することを表しています。

<b>バージョン2.0のハイライト：</b>

* リファクタードアーキテクチャ – プラグイン構造を改善して、パフォーマンスと統合を向上
* 今後の拡張サポート – このアップデートは、今後の新機能の追加を簡単に行うための基礎となります
* 幅広い互換性 – Macユーザーのサポートを含め、Blenderバージョン3.0以降と完全に互換性があります

<b>追加/更新：</b>

* [SRE] Substance engine選択のサポート（デフォルトはGPU）
* [SRE]テクスチャを書き出す新しい画像形式
* [SRE]各マップタイプのビット深度選択
* [BLD]価値出力のサポート
* [BLD]文字列入力のサポート
* [SRE]画像の書き出し先としてデフォルトの一時フォルダーを選択するオプションが追加されました

<b>修正済み：</b>

* [SRE]全体的なパフォーマンスの向上
* [BLD]統合ツールとブレンダー間の通信の問題を修正しました
* [BLD]統合ツールがインストール/開始できない
* [BLD]ブレンダーを閉じると、統合ツールが終了しない
* [BLD]マップのファイルタイプを変更してもマテリアルが更新されない
* [SRE]マテリアルのすべてのマップが常時書き出されます
* [SRE]統合ツールが階段のステップで法線マップをエクスポートする
* [SRE] Substanceの読み込みが完了しない
* [SRE]物理サイズユニットがシーンに調整されていない
* [BLD] Blenderで生成されたプリセットが他の統合と連携しない
* [BLD] マテリアルがサイクルで更新されない
* [BLD]入力のソフトリミットおよびハードリミットは無視される
* [BLD]パラメーターを調整するときに、カラーの適用度が正しく更新されない
* [SRE]統合ツールのアンインストールに失敗する
* [SRE]マテリアルを複数回複製するとエラーが発生する問題を修正しました。
* [SRE]画像ノードのカラースペースが、ユーザーの環境設定と正しく一致するようになりました。

<b>既知の問題：</b>

* Blender v4.0以降を使用している場合、複数回の有効化と無効化を行うとソケットが正しく表示されない
* Ctrl+Zで変更を取り消すと、エラーが発生する場合があります
* 空のファイルまたは.sbsarファイルではなくフォルダーを読み込むと、プラグインが壊れる可能性があります
* ブレンダーヘッドレスモードのサポート
