# アドオン0.9.3

**アドオンバージョン0.9.3+**&#x200B;のリリースノート

* アドオンの環境設定でOCIO 2.0のカラースペースラベルを追加します。
* ツールチップとしてパラメータ/出力ファクトリに説明を追加します。
* レポート機能を全体的に追加します（侵襲的なポップアップは削除され、ネイティブブレンダーメッセージに置き換えられました）。
* アドオン環境設定でインストールおよびアップデートを行う際に、SREバージョンラベルを更新します。
* アウトプットサイズとランダム化を修正する機能は、サブスタンスで使用できない場合があります。

**環境設定セクション：追加/更新：**

* デフォルトのシェーダードロップダウンから使用可能なプリセットとして物理サイズをサイクル/拒否します。
* 物理サイズのデフォルトの投影ブレンドのコントロール。
* Discordサーバーをポイントするようにサポートリンクを変更。
* アドオンの環境設定で正しい現在のSREバージョンが表示されるように修正します。
* 更新が必要な場合は、アドオンの互換性のあるバージョンをすべて表示します。
* SREが見つからない場合に、最初のバージョンではなくサポートされているバージョンの配列を表示します。

**Substance 3Dパネルセクション：追加/更新：**

* [グラフパラメータ]の下に、マテリアルの物理サイズが（メートル単位で）表示されます。
* 「シェーダー」ドロップダウンから「サイクル/イベント」 物理サイズを使用できます。
* すべてのパラメータが非表示の場合は、パラメータグループを非表示にします。
