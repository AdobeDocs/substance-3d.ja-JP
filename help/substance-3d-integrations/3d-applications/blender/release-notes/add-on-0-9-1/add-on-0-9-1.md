# アドオン0.9.1

**アドオンバージョン0.91+**&#x200B;のリリースノート

* 注意： *プラグインのバージョン0.91+は、以前のバージョンのプラグインとの下位互換性がありません。*
* プラグインのパフォーマンスと安定性を向上させるための内部コードベースの再アーキテクチャ
* UIを改善して全体的なユーザーエクスペリエンスを向上
* デフォルトのタイリングを変更できるUIが追加されました
* サイクルレンダービューでのテクスチャの更新をサポート
* サブスタンスの読み込みに失敗した場合に通知する、コンソールのエラー処理を追加
* クイックアクションでフローティングメニューを更新

**環境設定セクション：追加/更新：**

* Export Image Formatパラメーター。Blender内で生成されたイメージがマテリアルのイメージ入力として使用される場合、このフォーマットはイメージをTemporalフォルダーに保存するために使用されます。
* Sbsarライブラリパス。読み込みボタンを使用してサブスタンスファイルを検索したときに、デフォルトで開かれるフォルダーを指定します。
* 保存されていないファイルの書き出しを処理するためにSubstance 3d Painterで使用されるパスをエミュレートする、デフォルトのテクスチャ書き出しパス（時間フォルダー）
* テクスチャ相対パスは上記と同じですが、 $matNameなどのキーを使用してサブフォルダーを作成するオプションがあります。
* Sbsarファイルの相対パス：プロジェクトの保存時にブレンドファイルで使用されるsbsarファイルをパッケージ化するサブフォルダーを作成するためのパス
* 環境設定で異なるシェーダーネットワークを動的に設定する機能 – シェーダーネットワークでは、シェーダーのニーズに応じて、シェーダーごとに異なる変数を設定できます
* シェーダーネットワークの出力セクションでは、出力がデフォルトで有効かどうかを設定できます
* カラースペースを設定する機能（srgbだけでなく、ace、リニアexrおよびブレンダーフィルミックワークフローをサポートします）
* 画像形式とビット深度のデフォルトの選択
* シェーダーに定義されていない出力使用の値を設定する汎用出力。たとえば、マスクなど、シェーダーでデフォルトでは使用されていない別の出力がある場合に使用されます。
* 出力の種類を変更するためのフィルター（1：有効な出力のみ、2:シェーダーおよびSubstanceーのすべての出力、3:Substanceーで使用可能なすべての出力）
* カスタムショートカットのサポート（編集済み）

**Substance 3Dパネルセクション：追加/更新：**

* タイルと解像度のパラメーター値を調整してロックする機能
* プリセットUIの更新 – シェーダタイプドロップダウンで、ユーザーが使用するグラフのタイプを変更
* 画像入力パラメーターを、ブレンダーで使用される標準の画像入力に変更しました。 ファイルだけでなく、ブレンダー画像も使用できるようになりました
* 複数のBlenderインスタンスでいつでも作業できます
* ビューポートでマテリアルを選択したときに、Substance 3Dパネルでマテリアルを自動的にハイライト表示できるようになりました。
