# アドオンのアンインストール

アドオンをアンインストールするには、編集/環境設定/アドオンの順に移動し、アドオンのセクションを展開します。

1. まず、**[ツールのアンインストール]**&#x200B;ボタンをクリックして統合ツールを削除します。
1. 次に、**削除**&#x200B;ボタンを使用してアドオンファイルを削除します

>[!NOTE]
>
> Substance統合ツールを手動で削除する必要がある場合は、次のディレクトリからSubstance3DIntegrationToolsフォルダーを削除します
> 
> * **Windows**: C:\Users\（ユーザー名）\AppData\Roaming\Adobe
> * **Mac**: /Users/(username)/Library/Application Support/Adobe/Substance3DIntegrationTools
> * **Linux**: /home/(username)/Adobe/Substance3DIntegrationTools
