# 3Dアプリケーション

Substanceプラグインを使用して、ほとんどの主要なDCCアプリケーションでSubstanceファイル(.sbsar)を読み込むことができます。 プラグインは無料で、[アドビのサイト](https://www.substance3d.com/ecosystem-plug-ins/)またはネイティブインストーラーを介して入手できます。

* [3ds Max](../3d-applications/3ds-max/3ds-max.md)

* [Cinema 4D](../3d-applications/cinema-4d/cinema-4d.md)
