# 手続き型サンプリング

プロシージャルサンプリング設定を使用すると、プラグインがBrowninan、Noise、Fractal、Mandelbrotなどのプロシージャルテクスチャをサンプリングするサイズを制御できます。これらの設定は、手続き型テクスチャを使用するイメージ入力を持つSubstanceマテリアルに固有のものです。
