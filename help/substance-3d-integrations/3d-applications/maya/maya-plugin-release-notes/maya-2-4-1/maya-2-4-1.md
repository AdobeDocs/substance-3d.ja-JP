# Maya 2.4.1

<b>追加/更新：</b>

* Mayaプラグインでは、デフォルトでGPUが使用されるようになり、パフォーマンスとレンダリング速度が大幅に向上しました。

<b>修正済み：</b>

* MayaプラグインのSubstanceについてメニューのリンクを修正し、適切なリリースノートページにリダイレクトするようにしました。このページはhttps://helpx.adobe.com/substance-3d-integrations/3d-applications/maya/maya-plugin-release-notes.htmlを正しく指しています。
* Mayaプラグインで、マテリアルをリセットした後に、表示された解像度の値がUIで更新されず、解像度を含むすべての値がデフォルトの状態に正しくリセットされるようになりました。

Linux、macOS、Windowsで動作するMaya 2020、2022、2023用にMaya 2.4.1がリリースされました
