# Maya 2.1.5

2020年8月5日リリース

リストの変更：

* これでsbsarファイルが表示され、ファイルパスエディターで設定できるようになります
* プロジェクトを共有する場合、ファイルパスはMayaの相対パスで設定する必要があります
* SubstanceランチャーからのSend-toは、sbsarファイルをプロジェクトディレクトリにコピーするようになりました

このバージョンは、Linux、MacOS、WindowsではMaya 2017、2018、2019、2020、MacOS、WindowsではMaya LT 2018、2019、2020でリリースされています
