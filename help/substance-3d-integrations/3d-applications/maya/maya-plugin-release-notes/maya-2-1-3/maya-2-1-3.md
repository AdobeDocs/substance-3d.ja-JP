# Maya 2.1.3

2020年6月17日リリース

今日は、プラグインの2.1.3バージョンをリリースしました。

2.1.3リリース：

* これで、Windows上のインストーラーがSHA-256で署名されました。
* インストーラー内のすべてのバイナリがWindowsで署名されるようになりました
* substance\_link.dllとsubstance\_portal\_cli.dllに、Windowsでのバージョン/説明情報が追加されました
* Maya 2020の標準サーフェスのワークフローオプションが追加されました

このバージョンは、Windows、Linux、MacosのMaya 2017、2018、2019、2020でリリースされています。 Windows版およびMacOS版のMaya LT 2018、2019、2020でもリリースされています。
