# Maya 2.2.2

リストの変更：

* Substance 3D Remote Engineを8.4.2にアップデート
* Maya 2023のサポートの追加
* Maya 2023でArnold 7.1.0/MtoA 5.1.0のサポートを追加
* 「マップにワークフローを適用」を使用するArnoldワークフローで、Painter Arnoldテンプレートからの「メタネス」マップが正しく識別されるようになりました。
* プリセットを適用すると、解像度のドロップダウンが正しく更新されるようになりました
* &#39;substanceRunImageWorkflow&#39;コマンドは、作成された最終的なシェーダを返すようになりました
* &#39;substanceNodeApplyWorkflow&#39;コマンドは、作成された最終シェーダも返します
* &#39;substanceUtilityCreateAndLoad&#39;コマンドは、作成したsubstanceNodeを返すようになりました。

1. Linux、macOS、WindowsでのMaya 2017、2018、2019、2020、2022、2023用の2.2がリリースされました
