# Maya 0.9.11

**Maya 2.0の変更点：**\
**安定性**:

* グラフのダイナミックアトリビュートが、アトリビュートエディタコードではなく、ネイティブに作成されるようになりました
* Substanceノードは、UI入力を必要とせずに初期化されるため、バッチで作成できます
* アトリビュートエディタとプロパティエディタの安定性が大幅に向上
* メモリのパフォーマンスが大幅に向上し、GPUエンジンで8K出力を有効にするのに十分です
* 設定/環境設定が、Maya以外で簡単に編集できる別の設定ファイルとして保存されるようになりました

**スクリプト**:

* 強力なスクリプトAPI。入力、グラフ、出力情報の取得から、sbsarパッケージの読み込み、グラフの変更、プリセットマネージャーでのプリセット操作の実行まで、あらゆる操作が可能です。
* パブリックスクリプトAPIと同じ機能を使用するように設計されたUIコード

**Substance機能**:\
**プリセットのサポート：**

* デザイナーで設定した埋め込みプリセットがプリセットマネージャーに読み込まれる
* 複数のプリセットを含むsbsprsファイルの読み込みと書き出し
* プリセットマネージャー
* Engine V7のサポート
* Designer 2019.1でリリースされる新しいSubstanceエンジンで既に動作
* 数値出力は、のMaya出力アトリビュートにレンダーされます
* ハイパーシェードの他のノードにプラグインできるグラフ/サブスタンスノード

**ワークフローシステム：**

* Arnold、Renderman、VRay、Coronaなどの新しいワークフロー
* Pythonのカスタムワークフロー拡張機能
* ハイパーシェードからワークフロースクリプトをリバースし、カスタムワークフローを1回設定して保存します
* Substance Painterのイメージマップでのワークフローの使用

**UIとUXの改善：**

* ファイル/インポート.sbsarでsubstanceノードを作成
* sbsarファイルをファイルブラウザからハイパーシェードにドラッグアンドドロップして、substance 2ノードを作成します
* 属性は、Designerで設定されたカテゴリごとにレイアウトされるようになりました

**その他の改善点：**

* イメージ入力が手続き型ノードで機能するようになりました
* 手続き型ノードのサンプリングレートを設定して、手続き型イメージ入力をダウンまたはアップサンプルできるようになりました
* 出力ノードに、Substance Designerーでエンコードされた出力情報が表示されるようになりました
* Substance/グラフノードでグラフ情報（作成者など）を表示できるようになりました。
* 接続のオーバーライドや属性のオーバーライドなど、レイヤのオーバーライドのサポート
* キャッシュからディスクは、HDR出力のexrファイルタイプを選択します。この出力は、16ビット、16-floatまたは32-bit float出力を持ちます
* 古いプラグインからのリフレクション
* 新しいプラグインでシーンをロードすると、古いグラフと出力ノードがsubstance 2ノードに変換される
