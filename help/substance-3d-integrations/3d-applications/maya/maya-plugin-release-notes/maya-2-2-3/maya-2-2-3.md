# Maya 2.2.3

リストの変更：

* Maya 2019、2020および2022用にArnold 7.1.0/MtoA 5.1.0のサポートを追加
* Substanceグラフメタデータをスクリプト内のXMLストリングとして取得するための新しいスクリプトコマンド「substanceNodeGetGraphMetadata」が追加されました
* スクリプト呼び出しで範囲外グラフのクエリがクラッシュする問題を解決
* ArnoldおよびMtoAプラグインは、セマンティックなバージョン番号の間に「 – 」区切り文字を使用してディレクトリにインストールされるようになりました
* エンジンリソースの設定が適切に適用され、無視された部分が回帰を修正するようになりました。

1. 2.3がリリースされました
1. Linux、macOS、WindowsでのMaya 2017、2018、2019、2020、2022、2023
1. macOSおよびWindowsでのMaya LT 2018、2019、2020
