# Maya 2.1.2

2020年6月2日リリース

今日は、プラグインの2.1.2バージョンをリリースしました。

含まれる唯一の変更点は次のとおりです。

* Stingrayシェーダネットワーク作成時のMaya LTのエラーを修正しました。

これはMaya 2020.2でもリリースされ、Mayaインストーラに含まれています。

Maya 2017 ～ 2020とMaya LT 2018 ～ 2020の同じプラットフォームでリリースされています
