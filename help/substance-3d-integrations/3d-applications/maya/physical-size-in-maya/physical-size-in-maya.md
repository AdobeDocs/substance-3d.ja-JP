# Mayaの物理サイズ

Mayaの物理サイズ機能を使用すると、物理的なマテリアルと同じサイズでデジタルマテリアルを使用し、モデル上に正しいサイズでタイル状に並べたり、繰り返したりすることができます。 ファッションやスポーツウェア、インテリアのデザインやビジュアル化、映画やゲームの衣装のデザインなどに非常に役立ちます。

Mayaで任意のレンダラノードを作成した後は、単純にSubstance UIで物理サイズ機能を有効にすることができます。この機能は各Substance出力後に3平面のプロジェクションノードを作成し、プロジェクションのサイズをキャプチャ時に記録されたマテリアルの物理サイズに合わせます。

機能の使用方法について詳しくは、以下のチュートリアルを参照してください。

## この機能は現在、次のユーザーが使用できます。

Linux、macOS、WindowsでのMaya 2018、2019、2020、2022、2023

macOSおよびWindowsでのMaya LT 2018、2019、2020
