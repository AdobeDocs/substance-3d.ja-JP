# インストール

MayaプラグインのSubstanceは、Maya 2022/2020インストーラにも正式にインストールされます。 デフォルトでインストールが有効になっています。

>[!NOTE]
>
> **Maya 2022**
> 
> **Windows**: C:\Program Files\Allegorithmic\Adobe Maya用Substance 3D\2022\
> **MacOS**: /Applications/Allegorithmic/Adobe Substance 3D for Maya/2022\
> **Linux**: /opt/Allegorithmic/Adobe Substance 3D for Maya/2022

>[!NOTE]
>
> **Maya 2020**
> 
> **Windows**: C:\Program Files\Allegorithmic\Adobe Maya用Substance 3D\2020\
> **MacOS**: /Applications/Allegorithmic/Adobe Substance 3D for Maya/2020\
> **Linux**: /opt/Allegorithmic/Adobe Substance 3D for Maya/2020

また、プラグインの最新バージョンのインストーラは、[Maya用Substance 3DのAdobe](https://substance3d.adobe.com/plugins/substance-in-maya/)ページからダウンロードできます。
