# ワークフローをマップに適用

**[ワークフローをマップに適用]**&#x200B;を使用すると、エクスポートされたテクスチャをSubstance 3D PainterまたはペイントアプリケーションからMayaのマテリアルにすばやく適用できます。

**ワークフロー**&#x200B;オプションを使用すると、Arnoldなどの操作に使用するレンダラーを選択できます。

![](../../../assets/applymaps.png)

**複数のマップを選択**&#x200B;を使用して、左側に一覧表示されている命名規則に基づいて適用するマップを選択します。 *たとえば、\_ラフネスはラフネスチャンネルにマップされます。*

個々のマップを追加するには、フォルダーボタンをクリックしてテクスチャを選択します。
