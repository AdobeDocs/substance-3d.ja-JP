# プリセットの使用

Substanceファイルには、埋め込まれたプリセットファイルを含めることができます。 Substanceにプリセットファイルが埋め込まれている場合は、 Substanceプリセットウィンドウに表示されます。 Substanceパラメーターで選択した設定に基づいて、独自のプリセットを作成することもできます。

![](../../../assets/max9.png)

1. [プリセットを作成]は、3ds MaxのSubstanceに設定されているパラメータ設定に基づいて新しいプリセットを作成します。
1. 「プリセットの読み込み」を選択すると、プリセットファイル(.sbsprs)が読み込まれます。
1. 「プリセットを保存」を選択すると、現在選択されているプリセットのパラメーター値が保存されます。
1. 「選択したプリセットを書き出し」は、プリセットをプリセットファイル(.sbsprs)に書き出します。
1. 「すべてのプリセットを削除」を選択すると、プリセットリストのプリセットが削除されます。
1. 「選択したプリセットを削除」は、選択したプリセットのみを削除します。
