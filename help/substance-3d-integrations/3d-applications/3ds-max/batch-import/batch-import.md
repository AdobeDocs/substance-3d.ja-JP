# バッチ読み込み

バッチインポートを使用すると、複数の.sbsarSubstanceファイルをバッチインポートすることができます。

1. 3ds Max UIの上部にある[Substance設定]に移動し、[Substanceバッチ読み込み]を選択します。
1. インポートする.sbsarファイルを選択します。
