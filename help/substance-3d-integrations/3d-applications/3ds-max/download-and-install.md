# ダウンロードとインストール

プラグインの最新バージョンは、3ds Maxの最新の互換性のあるバージョンを使用してAutodeskによってネイティブに配布されます。 古いバージョンの特定のビルドが必要な場合は、以下のダウンロードリンクを参照してください。

* **Autodesk 3ds Max 2027用にダウンロード：** <https://www.adobe.com/go/substance3d-3dsmax-win-latest>
* **Autodesk 3dsMax 2026用にダウンロード：** <https://www.adobe.com/go/substance3d-3dsmax-win-2026>
* **Autodesk 3dsMax 2025用にダウンロード：** <https://www.adobe.com/go/substance3d-3dsmax-win-2025>
* **Autodesk 3dsMax 2024用のダウンロード** （プラグインバージョン3.1.0）: <https://www.adobe.com/go/substance3d-3dsmax-win-2024>
