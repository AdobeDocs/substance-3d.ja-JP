# Modoのインストール

プラグインをインストールするには、LPKファイルをMODOにドラッグします。 キットまたはMODOコンテンツパックをインストールしていない場合は、適切なフォルダを作成するように求めるダイアログが表示される場合があります。 キットをインストールすると、MODO UIの右上にSubstanceボタンが表示されます。
