# 参照の操作

## 参照の操作

マテリアルは、参照シーンで使用できます。 ただし、参照シーン内のSubstanceの出力を無効にする必要がある場合は、出力を手動で削除する必要があります。 MODOのデフォルトの参照プリファレンスを使用する場合、Substanceプロパティの出力をオフにしても、参照されるSubstanceの出力は削除されません。\
参照されるマテリアルが独自に生成された出力を削除手動で出力を削除できるようにするには、まずシーンの参照の上書きを変更する必要があります。 アイテム/参照/参照のオーバーライドを編集に移動し、削除を「アイテムで許可されている場合」に設定します。 これにより、Substance出力を手動で削除できます\
この変更が行われた後に開いている、または作成されたシーンのシェーダーツリーとクリップブラウザから。

参照の上書きの詳細については、MODOドキュメントを参照してください。\
<http://modo.docs.thefoundry.co.uk/modo/801/help/pages/modointerface/ImportReference.html>
